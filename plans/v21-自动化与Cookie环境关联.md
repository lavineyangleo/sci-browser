# v21 Playwright 自动化与 Cookie 环境关联
目标：为科研浏览器提供统一自动化入口，并把 Cookie 快照与真实浏览器环境、独立 profile、页面登录信号关联，避免将 Cookie 存在误判为已登录。
✅ 1. 检查现有 Cookie 导出、论文下载和源码发布结构。
✅ 2. 环境层：共享真实环境采集模块；记录 UA、语言、时区、屏幕、硬件信息及 SHA-256 摘要，不伪造指纹。
✅ 3. 会话层：扩展导出包含环境和登录信号；支持旧快照兼容及导入快照后的只读环境比较。
✅ 4. 自动化层：独立持久 profile，统一 open/collect/snapshot/check/download 命令；保留现有批量论文下载入口。
✅ 5. 验证与同步：真实浏览器页面验证、状态未知与差异处理、语法检查，更新本地 GitHub版本和使用文档。
当前展开第 2 步：环境摘要只描述采集字段，不视为身份凭证；登录识别依赖用户指定的可见页面选择器，无信号或冲突时返回 unknown。独立用户目录保存会话；不导入他人凭据，不自动绕过登录。
模块约定：新入口采用功能中文与版本命名；Python 包内使用标准包名以保证正常导入。

验证：真实 GitHub 未登录信号、同 profile 环境一致、跨 profile 差异、arXiv 标题采集和真实 PDF 下载通过；Cookie 1.0 校验兼容。网络曾出现连接重置，未将失败当作通过。尚未用用户账号验证已登录状态。
