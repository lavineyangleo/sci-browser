# 模块边界

启动器 app 调用 core；core 定位浏览器，并检查或启动 Python 本地服务。浏览器加载 sci-proxy 和 sci-cookie。

sci-proxy 的 UI 通过 background.js 与本地服务交互；core/routes-网站规则-v17.js 生成 PAC 并读取持久网站规则。ui/direct-直连规则-v19.js 只读显示规则，不改变路由。网页设置与弹窗共用后台接口。

services/mihomo/bridge/server.py 管理认证、状态持久化及内核进程；services/exit_probe.py 单独承担真实出口验证。settings.json、state.json 和 runtime 由运行环境生成，不属于源码。

论文下载 windows 适配层调用现有 Chromium，使用独立 profile；上游 scripts 负责元数据查询和重命名。Python 虚拟环境按工具隔离。

源码整理采用独立副本，保留原有可用相对路径，没有对正在使用的浏览器做破坏性重构。
